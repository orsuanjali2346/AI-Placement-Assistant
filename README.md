# 🎯 AI Placement Assistant

An AI-powered placement preparation platform that helps students analyze their resumes, evaluate ATS compatibility, match their skills with job descriptions, practice mock interviews, and follow a personalized learning roadmap.

## ✨ Features

### 📄 Resume Analyzer
- Upload and analyze resumes in PDF format
- Extract resume content automatically
- Generate AI-powered resume insights

### 📊 ATS Score
- Analyze resume ATS compatibility
- Generate an ATS score
- Identify skills and improvement areas
- Provide actionable resume suggestions

### 💼 Job Matcher
- Paste a job description
- Compare resume skills with job requirements
- Identify matching skills
- Detect missing job skills
- Calculate job match percentage

### 🎤 AI Mock Interview
- Generate interview questions using AI
- Supports Technical, HR, and Project-Based interviews
- Submit answers for AI evaluation
- Receive a score, strengths, improvements, and better-answer suggestions
- Prevents repeated interview questions during the session

### 🗺️ Learning Roadmap
- Generate a personalized learning roadmap
- Organize important placement preparation topics
- Track learning progress

### 📈 Progress Tracker
- Mark completed learning topics
- Track overall learning progress
- Display progress on the Dashboard

### 📊 Placement Dashboard
- View ATS score
- View skill match
- View job match
- View mock interview score
- Calculate overall placement readiness
- Get recommended next steps
- Monitor learning progress

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- PyMuPDF
- Pandas
- Python-dotenv
- Git & GitHub
